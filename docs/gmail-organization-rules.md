## 🎯 Orden de Prioridad de Clasificación

**IMPORTANTE:** El orden importa. Primera coincidencia gana.

1. **BLACKLIST** → Eliminar
2. **WHITELIST (Personal)** → Label "Personal"
3. **Admin Edificio** → Label "Admin Edificio"
4. **Filosofía** (remitentes OR keywords) → Label "Filosofía"
5. **Propuestas Laborales** (dominios) → Label "Propuestas Laborales"
6. **Educación/Cursos** (dominios) → Label "Educación/Cursos"
7. **Banking** (remitentes) → Label "Banking"
8. **Viajes** (remitentes) → Label "Viajes"
9. **Facturas** (remitentes) → Label "Facturas"
10. **Servicios Tech** (remitentes) → Label "Servicios Tech"
11. **Newsletters Tech** (remitentes) → Label "Newsletters Tech"
12. **MFA/Seguridad** (remitentes OR keywords) → Temporal (eliminar >15d)
13. **Notificaciones Sociales** (remitentes) → Eliminar
14. **Publicidad** (keywords) → Temporal (eliminar >30d)
15. **Gmail SPAM label** → Blacklist
16. **Gmail PROMOTIONS label** → Publicidad
17. **Sin categorizar** → Revisar manualmente

## 📅 Workflow Diario Propuesto

**Nombre:** `gmail-daily-maintenance`

**Frecuencia:** Diaria (ej: 6:00 AM Argentina time)

**Pasos:**

1. **Obtener emails nuevos** del día anterior
2. **Clasificar** cada email usando las reglas de prioridad
3. **Aplicar labels** según categoría
4. **Eliminar** emails que cumplan criterios de eliminación:
   - Blacklist (inmediato)
   - Notificaciones sociales (inmediato)
   - Viajes >30 días
   - MFA/Seguridad >15 días
   - Publicidad >30 días
5. **Archivar** emails >1 año de categorías específicas (Filosofía, Propuestas Laborales, Trabajo)
6. **Generar resumen** en Telegram:
   - Emails importantes recibidos (Personal, Filosofía, Propuestas Laborales)
   - Emails eliminados automáticamente
   - Emails que necesitan atención

**Ejemplo de mensaje Telegram:**


## 🛠️ Mantenimiento y Actualizaciones

### Agregar nuevo contacto a whitelist:
1. Editar `WHITELIST_EMAILS` en el script
2. Agregar email address (NO nombre)
3. Documentar en este archivo

### Agregar nuevo remitente a blacklist:
1. Editar `BLACKLIST_EMAILS` en el script
2. Agregar email address exacto
3. Documentar en este archivo

### Modificar reglas de retención:
1. Editar función `determineAction()` en el script
2. Actualizar este documento
3. Probar con dry-run antes de ejecutar

### Agregar nueva categoría:
1. Crear label en Gmail (manualmente o via script)
2. Agregar a `getCategoryLabel()` mapping
3. Agregar a reglas de clasificación
4. Actualizar este documento
